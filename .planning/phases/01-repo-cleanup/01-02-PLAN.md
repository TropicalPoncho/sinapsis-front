// ponytail: fija el comportamiento de color pre-r152 (hex crudo → shader, sin conversión
// sRGB→lineal implícita). Cada ThreeObject con shader propio fue calibrado visualmente contra ese

on. This file is the right home for the flag: `ThreeObject.js` (the base class every type extends)
imports `threeGlobal.js`, so it is guaranteed to load before any material is constructed. Setting
the flag here is what makes the three.js bump a complete upgrade rather than the half-upgrade
CONTEXT.md forbids.

Do not change the `resolveTHREE()` / `globalThis.THREE` fallback in that file. It exists for the old
AR path, which is out of scope; simplifying it would touch the 16 files that import this module for
no requirement.
