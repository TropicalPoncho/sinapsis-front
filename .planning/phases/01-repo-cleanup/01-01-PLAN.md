Version rationale — these are decisions, not defaults. Do not "helpfully" bump past them:

- **`three@^0.185.0`** (latest 0.185.1). Upgrade, not pin. The engine copied in by plan 02 was
  written against `three@0.147`, but every import path it uses still resolves in 0.185:
  `three/examples/jsm/renderers/CSS2DRenderer.js`, `three/addons/geometries/TextGeometry.js`,
  `three/addons/loaders/FontLoader.js`, `three/addons/loaders/HDRCubeTextureLoader.js`,
  `three/addons/math/ImprovedNoise.js`. The only behavioural break is the r152 color-management
  default, handled by one line in plan 02. Pinning to 0.147 would also break
  `three-custom-shader-material`, whose peer dep is `three >= 0.159`.
- **`three-custom-shader-material@^6.4.0`** is a NEW dependency. `LikeFireThreeObject.js` (part of
  the whole-directory copy in plan 02) imports `three-custom-shader-material/vanilla`. Its peers are
  `three >= 0.159` (satisfied), `react >= 18` (optional, satisfied by 19), `@react-three/fiber`
  (optional, not installed). No ERESOLVE.
- **`next@^15.5.22`, not 16.** The stack is locked at Next 15 in PROJECT.md ("ya está en el repo,
  no se reabre"). A framework major is not this phase's job.
- **`typescript@^5.9.3`, NOT 7.x.** TypeScript 7 GA'd in July 2026 with the Go-native compiler but
  without the stable programmatic API `typescript-eslint` needs, and `eslint-config-next` depends on
  `typescript-eslint`. Adopting it breaks `npm run lint`.
- **`tailwindcss@^3.4.19`, NOT 4.x.** v4 is a CSS-first `@theme` config model that drops the
  `tailwind.config.ts` + `postcss.config.mjs` setup this repo uses. That is a migration, not a bump.
- **`eslint-config-next@15.5.22`** pinned exact, matching `next` — Next's own convention.
