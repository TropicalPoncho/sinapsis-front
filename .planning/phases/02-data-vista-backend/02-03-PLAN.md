Crear `scripts/migracion/csv.ts` con dos funciones y nada más:

```typescript
export function escribirCsv(columnas: string[], filas: Record<string, string>[]): string
export function leerCsv(texto: string): Record<string, string>[]
```

Reglas exactas (subconjunto de RFC 4180, suficiente y verificable):
- Separador `,`. Fin de línea `\n`. La primera línea es el encabezado con `columnas` en orden.
- Al escribir, un campo se encierra en comillas dobles si contiene `,`, `"` o `\n`; las comillas
  internas se duplican (`"` → `""`). Un valor `undefined` o ausente se escribe vacío.
- Al escribir, **lanzar** si algún valor contiene `\n` o `\r`. Las planillas rompen los saltos de
  línea de formas distintas y este pipeline no los necesita: la prosa larga va a `metadata`, no al
  CSV. Es validación en un borde de confianza; falla ruidoso en vez de corromper la curaduría.
- Al leer, parsear respetando el comillado (una coma dentro de comillas no separa), aceptar `\r\n`
  y `\n`, ignorar la última línea si está vacía, y devolver un objeto por fila usando el
  encabezado como claves. Si una fila tiene distinta cantidad de campos que el encabezado, lanzar
  con el número de línea en el mensaje.

Se hace a mano, sin instalar `csv-parse`: son ~40 líneas, no hay librería de CSV en el repo, y el
formato acá está bajo control (una sola aplicación lo escribe, una planilla lo edita).

Al final del archivo, dejar la comprobación runnable que pide CLAUDE.md:
