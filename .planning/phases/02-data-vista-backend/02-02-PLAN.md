Crear `src/lib/vista/resolverVista.ts`. Firma exacta:

```typescript
import type { Vista, Subgrafo, NodoGrafo, VinculoGrafo } from '@/types/vista'
import type { Adyacencia } from './adyacencia.ts'

export function resolverVista(
  ady: Adyacencia,
  vista: Vista,
  yaCargados?: ReadonlySet<string>,
): Subgrafo
```

`yaCargados` es el tercer parámetro que resuelve VIST-03 **sin caso especial**: es el conjunto de
partida en lugar de `vista.raiz`. Pedir profundidad 1 con `incluirRaiz: false` sobre ese conjunto
es, literalmente, "los vecinos a un salto que todavía no están cargados". Una sola mecánica, dos
usos.

Nota de import: `Adyacencia` entra como `import type`, que se borra en compilación. Este archivo
no debe tener **ningún** import de valor — así corre tal cual bajo `node --test` y bajo el bundler
de Next sin diferencia.

**Algoritmo, paso a paso:**

1. **Conjunto inicial y bandera de global:**
   - Si `yaCargados` viene y no está vacío → `inicial = yaCargados`, `esGlobal = false`.
   - Si no, y `vista.raiz !== null` → `inicial = new Set([vista.raiz])`, `esGlobal = false`.
   - Si no → `inicial = new Set(ady.nodos.keys())`, `esGlobal = true`.
   - Descartar del inicial cualquier id que no exista en `ady.nodos`.

2. **Alcanzados:** `alcanzados = new Map<string, number>()` de id → profundidad, en orden de
   descubrimiento (los `Map` de JS preservan orden de inserción; eso es lo que hace determinista
   el truncado por `limite`).
   - Si `esGlobal`, un id del inicial entra solo si `pasaFiltroNodo(nodo)`.
   - Si NO es global, todo el inicial entra con profundidad 0 **sin pasar por los filtros de nodo**:
     la raíz (o el conjunto ya cargado) es el ancla de la Vista, no un resultado de búsqueda. Sin
     esto, "las obras de este artista" filtrado a OBRA borraría al artista.

3. **BFS por niveles**, desde profundidad 0 hasta `vista.profundidad - 1` inclusive:
   para cada `id` del nivel actual, juntar las aristas candidatas según `vista.direccion`:
   - `'sale'`  → `ady.sale.get(id) ?? []`
   - `'entra'` → `ady.entra.get(id) ?? []`
   - `'ambas'` → las dos concatenadas
   Para cada arista `v`:
   - si `!pasaFiltroVinculo(v)` → se ignora (no se traversa ni se devuelve).
   - el vecino es `v.origen === id ? v.destino : v.origen`.
   - si ya está en `alcanzados` → nada.
   - si el nodo del vecino no existe en `ady.nodos` → nada.
   - si `!pasaFiltroNodo(nodo)` → nada.
   - si no → `alcanzados.set(vecino, profundidadActual + 1)`.

4. **incluirRaiz:** si `vista.incluirRaiz === false` y `!esGlobal`, borrar de `alcanzados` todos
   los ids de `inicial`. En la vista global no hay raíz que sacar, así que `incluirRaiz` no aplica.

5. **limite:** si `vista.limite` está definido y `alcanzados.size > vista.limite`, quedarse con los
   primeros `vista.limite` en el orden natural del `Map` — que es profundidad ascendente porque el
   BFS inserta por niveles. Agregar acá:
   ```typescript
   // ponytail: modoOrden 'geo' y 'aleatorio' caen al mismo orden de BFS que 'grafo'. La semántica
   // de 'geo' está sin definir en el contrato y solo 3 nodos del dump tienen datos de ubicación;
   // 'aleatorio' necesitaría una fuente de azar, que rompería la pureza de esta función. Se
   // resuelven cuando el orden se vuelva visible (fase 3 o 4), pasando un comparador desde afuera.
   ```

6. **nodos:** mapear los ids que quedaron a través de `ady.nodos`.

7. **vinculos:** el conjunto visible es `alcanzados ∪ inicial` (la unión incluye a la raíz aunque
   `incluirRaiz` sea false: es lo que evita aristas huérfanas en el `aditivo` del motor). Recorrer
   `ady.sale.get(id)` para cada id del conjunto visible, y quedarse con las aristas que
   (a) tengan ambos extremos en el conjunto visible y (b) pasen `pasaFiltroVinculo`. Deduplicar por
   `v.id` con un `Set` — recorrer solo `sale` ya evita el doble conteo, pero el `Set` lo deja
   explícito y barato.

**Los dos predicados, exactos:**

```
pasaFiltroVinculo(v: VinculoGrafo): boolean
  - si vista.filtroVinculos.length > 0 y no incluye v.tipoVinculo → false
  - si vista.filtroRoles está definido y tiene largo > 0:
      si v.rol es undefined o no está en filtroRoles → false
  - true
  (array vacío = sin filtro. Si el array vacío significara "ninguno", ninguna Vista neutra
   devolvería nada.)

pasaFiltroNodo(n: NodoGrafo): boolean
```
